### CI и worker

- [x] Управляемая отмена через `agent ci cancel/cancel-check` и явная замена
  `agent ci prepare --retry-of` для другого worker. Отмена сохраняется на Drive
  и в локальной очереди, останавливает собственные процессы и подтверждается
  проверенным CANCELLED. После включения прежнего host отменённое задание
  из локальной очереди не запускается; новый job сохраняет связь retry_of.
  Автоматическая политика таймаутов/назначения и retention остаются открытыми.
- [x] Защита от позднего результата отменённой попытки. Worker проверяет отмену
  при восстановлении, во время доставки и до/после upload результата;
  отдельный `cancelled/` сохраняет исходные immutable файлы. Клиент и агент
  блокируют поздний PASS, проверяют полный CANCELLED и не применяют старый PASS
  через pull --passed. Проверенный cancel marker сохраняется локально;
  его исчезновение на Drive не снимает отмену. GC учитывает незавершённую отмену.
  Проверены частичная доставка, потерянные ответы, restart и повтор удаления
  inbox после PUBLISHED без повторного запуска CI. Завершены 54 проверки CI,
  агентского обмена, GC и восстановления, включая отдельный процесс worker.
- [x] Базовая пауза discovery и периодической публикации CI по умолчанию 30 секунд,
  максимум паузы polling в простое/при сетевых ошибках — 120 секунд.
  Локальный heartbeat раз в 5 секунд не обращается к Drive; публикация отправляет
  снимок статуса и новые log chunks отдельно. Обоснование квот и интервалов
  описано в docs/worker.md; 30 секунд — выбор gdi, не требование Google.
- [x] Передача proxy environment host в act через приватный env-файл с правами 0600,
  без credentials в argv или опубликованных artifacts. Поддержаны верхний/нижний
  регистр переменных и NO_PROXY для локальных artifact/cache endpoints.
- [x] Рабочая git metadata внутри act: изолированный checkout сохраняет ref точного
  SHA и detached HEAD; act копирует служебные файлы независимо от gitignore.
  Проверены git rev-parse/show внутри CI-контейнера.
- [x] Проверенная временная сборка act 0.2.89 с upstream PR #6115 для ZIP artifacts:
